# FAQ

**Q: Is this the real Jarvis personal vault?**  
A: No. This is a sanitized sample vault for a public demo.

**Q: Which model does the demo use?**  
A: GPT-4o mini only. Model switching is disabled.

**Q: Can I upload my own notes?**  
A: Not in this demo. Retrieval is limited to the shipped sample notes.

**Q: Why do I need an account?**  
A: Email auth lets the server apply per-user rate limits and keep the API closed
to anonymous callers.
