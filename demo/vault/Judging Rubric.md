# Judging Rubric

Judges score demos on four equal axes (1–5 each):

| Axis | Looks for |
|------|-----------|
| Clarity | Can a newcomer understand the pitch in 60 seconds? |
| Reliability | Does the demo stay up under light concurrent use? |
| Safety | Are secrets server-side? Is abuse rate-limited? |
| Craft | Is the UI / API readable without enterprise clutter? |

Bonus note (not scored): reuse of boring, auditable patterns over novel infra.
