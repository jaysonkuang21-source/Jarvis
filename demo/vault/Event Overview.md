# Event Overview

**NASA Hackathime** (fictional demo event) is a weekend showcase where student
teams build assistive and exploration-tech prototypes.

## Goals

- Ship a working demo, not a slide deck alone
- Prefer open tools and clear documentation
- Show responsible use of AI (rate limits, no secret leakage)

## Audience

Judges, mentors, and visiting students. Typical attendance is tens of people
with bursts up to a few hundred concurrent site visitors during demos.
